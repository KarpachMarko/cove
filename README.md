# Cove

A personal music client for iPhone and Android, connecting a Navidrome library with discovery through ZenSync providers. The visual reference is Apple Music, with a focus on browsing and playing your own collection.

This repository starts with design assets and planning documents. No application scaffold, runtime dependencies, or backend integration has been added.

- [Initial project scope and implementation plan](PLAN.md)
- [Design inventory and provenance](docs/design/README.md)
- [Interactive mobile mockups](docs/design/mobile-concepts/index.html)
- [Original app-icon concepts](docs/design/app-icons/index.html)
- [Ten pink Cove icon concepts](docs/design/app-icons/cove-pink/index.html)

Open the HTML files directly in a browser; they need no build step or server. The mockups use fictional music, simulated playback, and simulated provider results. Each design directory includes its original notes, and the mobile concepts include PNG exports.

Application architecture and the final icon remain to be selected. Use pnpm for future JavaScript dependencies and scripts; see [AGENTS.md](AGENTS.md) for development conventions.
